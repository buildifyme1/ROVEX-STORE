ROVEX Homepage + Product Details + Cart + Checkout UI
تشغيل المشروع:
1) فك ضغط الملف.
2) افتح مجلد ROVEX-Homepage في VS Code.
3) افتح index.html باستخدام Live Server أو افتحه مباشرة في المتصفح.
الملفات: index.html / style.css / script.js
المميزات: صفحة رئيسية، تفاصيل منتج، اختيار المقاس واللون والكمية، سلة تحفظ بياناتها محليًا، نموذج Checkout تجريبي.
تنبيهات مهمة:
- الصور والأسعار تجريبية ويجب استبدالها ببيانات وصور المنتجات الحقيقية.
- السلة تحفظ محليًا في نفس المتصفح عبر localStorage.
- Checkout يتحقق من المدخلات محليًا فقط ولا يرسل طلبًا حقيقيًا.
- لا توجد قاعدة بيانات أو بوابة دفع متصلة. قبل استقبال طلبات فعلية يجب ربط Backend/Supabase والتحقق من البيانات على الخادم ودمج بوابة دفع معتمدة.
